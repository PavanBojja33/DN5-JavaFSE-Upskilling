Customizing Bootstrap via _variables.scss

Exercise 19.2: Customize primary colors and border-radius via _variables.scss.

Steps to customize Bootstrap variables:
  1. Create custom.scss and override variables before importing Bootstrap: 
    // Override primary color and border-radius
$primary: #6f42c1;
$border-radius: 1rem;

@import "../node_modules/bootstrap/scss/bootstrap";
  2. Recompile: npx sass custom.scss custom.css
  3. Link the compiled CSS in your HTML.
This box would appear with the custom purple primary color after recompiling Sass.

Customization with Sass - Setup

Exercise 19.1: Set up a Bootstrap 5 project with Sass using npm.

Steps to set up Bootstrap 5 with Sass:
  1. Initialize npm project: npm init -y
  2. Install Bootstrap and Sass: npm install bootstrap sass
  3. Create a file custom.scss and import Bootstrap: 
    @import "../node_modules/bootstrap/scss/bootstrap";
  4. Compile Sass: npx sass custom.scss custom.css
  5. Link the compiled CSS in your HTML: 
    <link rel="stylesheet" href="custom.css">
Sass setup is now ready for Bootstrap 5 customization!
